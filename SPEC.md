# Problem

Voluntary organisations in Innlandet need help preparing funding applications. The provisional project will initially use only the Regional Culture Fund. This choice awaits discussion with the lecturer.

The weather application is an earlier practice exercise.

# Users

The intended users are people preparing funding applications for voluntary organisations in Innlandet.

Planned input is approved public rule excerpts and synthetic, non-identifying preparation answers.

Planned output is a sourced preparation checklist that marks missing or unknown information.

# Definition of success

Requirements in the checklist must match the approved excerpts. Citations must be preserved, and unsupported conclusions must be flagged. The checklist must not guarantee eligibility or funding.

The current implementation includes a timeline-status checker with four previously passing tests, and an offline probe with a checked normal output and three passing synthetic error-case tests. These checks do not establish live performance. AI interpretation, application-document/date validation and the full funding workflow remain pending.
