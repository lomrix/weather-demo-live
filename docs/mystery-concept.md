# The Last Recording

Short planning draft. This is a proposal; nothing is implemented yet.

- **Intended users:** Game-night organisers in Innlandet.
- **Proposed need — unverified:** Preparing cooperative mysteries takes time. Whether organisers need this tool still needs validation.
- **Input:** A manually authored fictional case, including its solution, timeline, clue facts, player count and difficulty.
- **Proposed workflow:** Validate the case, use an agent to prepare player clue sheets and a host guide, then run automatic checks.
- **Proposed success checks:** Required clue facts are preserved, the timeline is consistent, and the structured puzzle rules allow exactly one solution.
- **Human review:** Fairness, atmosphere and enjoyment need playtesting; automatic checks cannot establish these qualities.
- **First scope:** One short case with three suspects.

[Terningkast 7](https://terningkast7.no/) describes a gaming association and game nights in Hamar, Innlandet. This is evidence of a local gaming audience, not evidence that organisers need this tool.
