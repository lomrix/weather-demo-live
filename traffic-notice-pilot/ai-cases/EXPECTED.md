# Første måling av Ollama-uttrekket

Tekstfilene er korte, manuelt omskrevne testdata basert på de kjente sakene. Kjør samme filer med begge modellene. Først etter dette kan vi prøve hele artikler.

| Fil | Sjekk manuelt i svaret |
| --- | --- |
| koigen | Gangsti stenges under arbeid. Publiseringsdato skal ikke brukes som stengedato. |
| gasbuvegen | Buss og utrykningskjøretøy kan passere i perioder. Teksten gir ingen konklusjon om gående. |
| basar | Bilstenging og fortsatt passasje for gående og syklende skal fremgå. Eksemplet er historisk. |
| cc-hamar | Riktig retning og omtrentlig varighet. Ingen eksakt sluttdato eller årstall lagt til i sitatet. |

Registrer modell, sak, om Python godtok svaret, og om innholdet traff forventningen. Et godkjent sitat kan fortsatt ligge i feil felt. Noter også om modellen mister et unntak. Skriptet oppdaterer ingen trafikkort eller ruter.
